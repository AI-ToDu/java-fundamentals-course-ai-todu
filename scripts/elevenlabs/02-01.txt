Una variable nos permite guardar un dato y darle un nombre para utilizarlo después. Nuestra mascota necesita un nombre y una cantidad de energía. String representa texto, por eso Luna va entre comillas. El tipo int representa números enteros, como cuarenta o veinte. El tipo double permite representar números con parte decimal, como el peso de tres punto cinco. En el código usamos punto para escribir ese decimal. El tipo boolean representa uno de dos valores: verdadero o falso. Elegir el tipo ayuda a expresar qué dato esperamos. El nombre de cada variable debe explicar su propósito.
