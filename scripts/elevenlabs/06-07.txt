Empezamos mostrando un mensaje y terminamos con un programa que lee datos, calcula, decide, repite y trabaja con objetos. Una variable guarda información. Un método organiza una tarea. Una clase define estado y comportamiento; cada objeto tiene su propio estado. Un array reúne elementos para recorrerlos. La encapsulación nos permitió mantener la energía dentro de un rango válido. No necesitas memorizar cada línea para seguir aprendiendo. Vuelve a los ejemplos, cambia un dato y predice el resultado antes de ejecutar. Como siguiente reto, diseña una acción para jugar que reduzca la energía sin bajar de cero. Ya tienes las herramientas para intentarlo.
