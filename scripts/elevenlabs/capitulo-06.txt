Un array permite reunir varios elementos del mismo tipo en una estructura ordenada. Aquí escribimos Mascota seguido de corchetes para indicar un array de referencias a objetos Mascota. Dentro colocamos dos mascotas: una usa el nombre que escribe el usuario y la otra se llama Sol. No copiamos de nuevo el código de la clase para cada mascota; creamos objetos de la misma clase. El array que acabamos de crear tiene dos posiciones y su tamaño queda fijo. Si queremos un ejemplo con tres mascotas, podemos cambiar esta inicialización antes de ejecutar. Más adelante existen otras estructuras para colecciones que cambian de tamaño, pero hoy trabajaremos con arrays.

Cada posición del array tiene un índice. En Java los índices comienzan en cero. Con dos mascotas, los índices válidos son cero y uno. La propiedad length nos indica cuántas posiciones tiene el array: en este caso devuelve dos. Esa cantidad no es el último índice. Si intentáramos acceder al índice dos, estaríamos fuera del array y el programa fallaría. Esta diferencia explica por qué muchos recorridos usan menor que la longitud y no menor o igual. Puedes imaginar dos casillas numeradas desde cero. Cuenta las casillas y después observa la etiqueta de la última: son números diferentes.

Recorremos el array con un for que comienza en cero y continúa mientras el índice sea menor que la longitud. En cada vuelta obtenemos la mascota de esa posición. La variable mascota representa el objeto que estamos atendiendo en esa vuelta. Mostramos su energía, lo alimentamos y mostramos el resultado. Con treinta de comida, Luna pasa de cuarenta a setenta y Sol pasa de setenta a cien. El mismo bloque funciona para ambas. No necesitamos preguntar manualmente si estamos en la primera o la segunda mascota. El recorrido selecciona cada elemento y la clase se encarga de aplicar su comportamiento y sus reglas.

El nombre que devuelve get nombre es una cadena, un String. Podemos usar sus métodos para trabajar con ese texto. En el ejemplo consultamos length y mostramos la longitud del nombre. Luna tiene cuatro letras y Sol tiene tres. Observa una diferencia de escritura: para el array usamos length sin paréntesis; para String llamamos al método length con paréntesis. No son la misma operación aunque sus nombres se parezcan. En estos nombres simples el resultado coincide con el número de letras; con algunos símbolos y emojis el conteo de una cadena puede ser más complejo. Hoy usaremos palabras sencillas para concentrarnos en cómo obtener el dato de cada objeto.

Sigamos el programa completo. Primero leemos el nombre y una cantidad entera. Validamos esa cantidad antes de crear las mascotas. Después construimos los dos objetos y los guardamos en el array. Finalmente recorremos el array y trabajamos con cada mascota. Cada parte tiene una responsabilidad que ya conocemos. Si la entrada es texto en lugar de un entero, mostramos el mensaje y terminamos. Si la cantidad está fuera del rango, también terminamos. Si la cantidad es cien, ambas mascotas quedan con energía cien porque el setter limita la suma. Probar casos normales, límites y entradas incorrectas nos ayuda a verificar el comportamiento desde distintas situaciones.

Empezamos mostrando un mensaje y terminamos con un programa que lee datos, calcula, decide, repite y trabaja con objetos. Una variable guarda información. Un método organiza una tarea. Una clase define estado y comportamiento; cada objeto tiene su propio estado. Un array reúne elementos para recorrerlos. La encapsulación nos permitió mantener la energía dentro de un rango válido.
