¿Te gustaría crear una mascota que tenga nombre, energía y acciones propias? En este curso vamos a construirla con Java. Empezaremos con un mensaje en pantalla y avanzaremos paso a paso hasta manejar varias mascotas. No necesitas saber programar. Programar consiste en escribir instrucciones precisas para que una computadora realice una tarea. Java es un lenguaje que permite expresar esas instrucciones y se utiliza para crear muchos tipos de aplicaciones. Hoy construiremos un programa de consola: nos comunicaremos con él mediante texto. Solo necesitas tu navegador y ganas de probar.

Abre el editor Java que aparece en los recursos de esta lección. En él encontrarás un espacio para escribir el programa, una opción para ejecutarlo y una zona donde aparecerá el resultado. El navegador envía el código a una computadora que tiene Java preparado y nos devuelve la salida. Por eso no necesitamos instalar herramientas. Copia el primer ejemplo y conserva el nombre de la clase: Main. Si ya hay otro programa, reemplázalo por completo para evitar mezclar dos ejemplos. Ubica la opción de ejecutar y la zona de salida. En unos segundos las utilizaremos.

Observa la estructura del programa. La primera línea declara una clase llamada Main. Dentro aparece un método llamado main, que será el punto de entrada de estos ejemplos. No necesitas memorizar ahora todas las palabras que lo acompañan. Conservaremos esa estructura mientras aprendemos. Las llaves agrupan instrucciones: una pareja delimita la clase y otra delimita el método. Dentro escribimos dos instrucciones que muestran mensajes. Cada una termina con punto y coma. Las comillas indican dónde empieza y termina el texto. Los espacios y la sangría nos ayudan a ver qué instrucciones pertenecen al mismo bloque.

Pulsa ejecutar. La consola muestra primero Hola, mundo y después el segundo mensaje. El programa siguió el orden de nuestras instrucciones. Ahora quitaremos un punto y coma para ver un error frecuente. Al ejecutar, Java detecta un problema y nos da información para localizarlo. Un error no significa que no puedas programar: significa que tenemos algo concreto que revisar. Busca la línea indicada y observa también la línea anterior. Recupera el punto y coma y ejecuta otra vez. Cuando cambies un programa, comprobar su resultado es tan importante como escribirlo.

Tu primer reto es cambiar el mensaje y agregar una segunda instrucción para presentar a tu futura mascota. Puedes escribir: Mi mascota se llama Luna. Conserva las comillas, los paréntesis y el punto y coma. Tienes un momento para intentarlo; si necesitas más tiempo, pausa el video. Al ejecutar deberías ver dos líneas. Ya sabes abrir un editor, modificar instrucciones y comprobar la salida. Ahora vamos a guardar información para que el programa pueda trabajar con ella.
