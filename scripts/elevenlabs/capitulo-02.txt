Una variable nos permite guardar un dato y darle un nombre para utilizarlo después. Nuestra mascota necesita un nombre y una cantidad de energía. String representa texto, por eso Luna va entre comillas. El tipo int representa números enteros, como cuarenta o veinte. El tipo double permite representar números con parte decimal, como el peso de tres punto cinco. En el código usamos punto para escribir ese decimal. El tipo boolean representa uno de dos valores: verdadero o falso. Elegir el tipo ayuda a expresar qué dato esperamos. El nombre de cada variable debe explicar su propósito.

Lee esta declaración de izquierda a derecha: necesitamos un entero, lo llamamos energía y le asignamos el valor cuarenta. El signo igual guarda el valor de la derecha en la variable de la izquierda. No pregunta si dos cosas son iguales; más adelante usaremos una comparación para eso. Cuando escribimos el nombre de una variable sin comillas, usamos el dato que contiene. Si ponemos ese nombre entre comillas, obtenemos solamente el texto. Podemos cambiar el valor inicial y volver a ejecutar. Observa que los cálculos se actualizan porque usan las variables. No es necesario reescribir cada resultado a mano.

Los operadores nos permiten combinar valores. Si la energía empieza en cuarenta y la comida aporta veinte, una suma produce sesenta. Guardamos ese resultado en otra variable. Después restamos quince para representar el costo de jugar y obtenemos cuarenta y cinco. Antes de ejecutar, intenta calcular los resultados tú mismo. Así puedes comprobar si el programa hace lo que esperabas. También podemos multiplicar: el asterisco representa la multiplicación y nos permite calcular el doble de una cantidad. Una expresión es una combinación de valores y operadores que produce un resultado. Usaremos expresiones tanto para calcular como para tomar decisiones.

La división merece atención. Cuando dividimos dos enteros, como cinco entre dos, Java realiza una división entera y el resultado es dos. La parte fraccionaria no aparece en ese resultado. Si uno de los valores es decimal, como cinco punto cero, la división produce dos punto cinco. No son resultados contradictorios: dependen de los tipos que participan. Los paréntesis ayudan a indicar qué operación queremos resolver primero y a mostrarla claramente dentro de un mensaje. Si un resultado te sorprende, revisa los valores y sus tipos antes de cambiar todo el programa. Esa costumbre evitará muchos errores.

La expresión energía menor que cincuenta produce un booleano. Con energía cuarenta, la comparación es verdadera; con energía setenta, es falsa. En la consola verás las palabras true y false, que son los valores de Java. Para comparar números también existen mayor que, menor o igual y doble igual. Recuerda: un igual asigna, dos iguales comparan. El signo más también puede unir texto y datos en un mensaje. En Nombre más la variable nombre, construye una frase. Mira el contexto para distinguir una suma numérica de una unión de texto. En ambos casos podemos predecir la salida antes de ejecutar.
