El nombre que devuelve get nombre es una cadena, un String. Podemos usar sus métodos para trabajar con ese texto. En el ejemplo consultamos length y mostramos la longitud del nombre. Luna tiene cuatro letras y Sol tiene tres. Observa una diferencia de escritura: para el array usamos length sin paréntesis; para String llamamos al método length con paréntesis. No son la misma operación aunque sus nombres se parezcan. En estos nombres simples el resultado coincide con el número de letras; con algunos símbolos y emojis el conteo de una cadena puede ser más complejo. Hoy usaremos palabras sencillas para concentrarnos en cómo obtener el dato de cada objeto.
