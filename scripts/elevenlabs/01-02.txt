Abre el editor Java que aparece en los recursos de esta lección. En él encontrarás un espacio para escribir el programa, una opción para ejecutarlo y una zona donde aparecerá el resultado. El navegador envía el código a una computadora que tiene Java preparado y nos devuelve la salida. Por eso no necesitamos instalar herramientas. Copia el primer ejemplo y conserva el nombre de la clase: Main. Si ya hay otro programa, reemplázalo por completo para evitar mezclar dos ejemplos. Ubica la opción de ejecutar y la zona de salida. En unos segundos las utilizaremos.
