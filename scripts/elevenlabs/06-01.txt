Un array permite reunir varios elementos del mismo tipo en una estructura ordenada. Aquí escribimos Mascota seguido de corchetes para indicar un array de referencias a objetos Mascota. Dentro colocamos dos mascotas: una usa el nombre que escribe el usuario y la otra se llama Sol. No copiamos de nuevo el código de la clase para cada mascota; creamos objetos de la misma clase. El array que acabamos de crear tiene dos posiciones y su tamaño queda fijo. Si queremos un ejemplo con tres mascotas, podemos cambiar esta inicialización antes de ejecutar. Más adelante existen otras estructuras para colecciones que cambian de tamaño, pero hoy trabajaremos con arrays.
